# 小米闹钟 · ESP32-S3 新板硬件接线表

> 主控：Seeed Studio XIAO ESP32-S3 (Sense) 模组，8MB Flash / 8MB PSRAM
> 对应固件：`ino/ino.ino` **v4.0**（由 ESP32-C3 版 v3.15 移植）
> 原始输入：`../硬件接线表.md`（用户提供的 10 行速记版，本表是它的展开与核对结果）
> 用途：PCB 绘制 / 打样焊接 / 上电自检对照
> **本文引脚以固件顶部 `#define PIN_xxx` 为准，改脚时两边一起改。**

## 1. 主控引脚分配

| 管脚 | 网络名 | 方向 | 接到 | 备注 |
|---|---|---|---|---|
| GPIO0 | KEY1 / BOOT | IN | 主按键 → GND | 内部上拉。**strapping 脚**，上电瞬间别按着，否则进下载模式。短按=停铃/点亮 3s，中按(0.8~3s)=切 12·24H，长按 3s=配网 |
| GPIO1 | TM1652_SDA | OUT | 灯板单线 SDA | 原始速记写作 `GPIO1-TM1652EN`，已与用户确认：**就是数据线，不是电源使能** |
| GPIO2 | KEY2 | IN | 副按键 → GND | 内部上拉，长按 8s 恢复出厂（第 5s 起屏上倒数 3·2·1） |
| GPIO4 | MIC_WS | OUT | ICS-43434 WS / LRCK | I2S_NUM_1，16kHz 位时钟的帧同步 |
| GPIO5 | MIC_SCK | OUT | ICS-43434 SCK / BCLK | 16kHz × 32bit × 2 = 1.024MHz |
| GPIO6 | MIC_DIN | IN | ICS-43434 SD | 32bit 帧，高 24bit 为有效数据 |
| GPIO7 | SPK_DOUT | OUT | MAX98357 DIN | I2S_NUM_0，44.1kHz / 16bit / 立体声 |
| GPIO8 | SPK_BCLK | OUT | MAX98357 BCLK | 44.1kHz × 16bit × 2 = 1.4112MHz |
| GPIO9 | SPK_LRCK | OUT | MAX98357 LRCK / WS | |
| GPIO10 | WS2812B_DIN | OUT | 两颗 WS2812B 串联 | RMT 单帧推 2×24bit，GRB 线序 |
| CHIP_PU | RESET | — | 复位键 → GND | XIAO 模组自带，见原理图 3 脚 |
| GPIO3 | — | — | **空闲** | strapping 脚，留空不要接下拉 |
| GPIO21 | — | — | **空闲** | 模组上 USER_LED / Sense 扩展板 SD_CS |
| GPIO41 / GPIO42 | — | — | **空闲** | 模组内置 PDM 麦克风数据/时钟，本固件不用 |
| GPIO26~37 | — | — | 模组内部 Flash / PSRAM | 不可用（PSRAM 在本固件里关闭，但仍不要占用） |

> 没有出现在这张表里的外设：**DS1302 RTC、光敏、PAM8403 全部取消**。
> 时间只靠 NTP，断电即丢，重新上电联网后几秒内恢复。

## 2. TM1652 灯板

| 灯板 | 接到 | 备注 |
|---|---|---|
| VCC | 5V | 见下方电平风险 |
| GND | GND | |
| SDA | GPIO1 | 单线串口，只写，位延时 49µs |

沿用 C3 版的 6 字节显存与段码表（`frame[6]`、`SEG_NUM[]`），固件里驱动代码一行没改，只改了 `PIN_TM1652`。

### 电平风险（沿用旧板结论）

灯板走 5V 时 TM1652 的 VIH ≈ 0.7×VDD = 3.5V，而 ESP32-S3 只能输出 3.3V，处在边缘状态。旧板实测能跑，但换批次有风险，三选一：

1. 灯板 VDD 降到 4.5V（串一只肖特基二极管）
2. 加一级单向电平转换（74LVC1T45 等）
3. SDA 串 100~330Ω 限流，并确认灯板 SDA 上**没有 5V 上拉**（有的话会灌进 GPIO1）

座子引脚顺序装机前对着实物灯板丝印再核一遍，接反直接烧板。

## 3. 音频输出（MAX98357，I2S）

```
GPIO9 (LRCK) ── MAX98357 LRCK
GPIO8 (BCLK) ── MAX98357 BCLK
GPIO7 (DOUT) ── MAX98357 DIN
```

- 标准 Philips I2S，44.1kHz / 16bit / 立体声；左右声道送同一份方波样本。
- MAX98357 是**数字输入**功放，不需要 C3 版那套 R8/R9 分压 + C17 隔直电容，也不要接 PAM8403 的模拟输入网络。
- GAIN / SD 模式脚按 datasheet 接（默认 9dB；SD 悬空/拉高决定关断与声道选择）。**建议把 SD 脚留出测试点**，需要静音/省电时可再接空闲 GPIO。
- 喇叭是 BTL 输出，SPK- 是驱动输出不是地，负极绝不能接 GND 或外壳。
- 老固件「10 档音量 = LEDC 占空比 1~25」不再适用：现在 1~10 档线性映射到 `I2S_AMP_MAX = 10000`（约满量程 30%）。装机后太吵/太轻改这一个宏。
- 音头/收尾仍保留约 6ms 幅度渐变（在 `i2sFeedTask` 里做），避免阶跃产生「哒」声。

## 4. 麦克风（ICS-43434，I2S 输入）

```
GPIO5 (SCK) ── ICS-43434 SCK   (pin 4)
GPIO4 (WS)  ── ICS-43434 WS    (pin 1)
GPIO6 (DIN) ── ICS-43434 SD    (pin 6，麦克输出 → ESP32 输入)
LR          ── GND(左声道) 或 VDD(右声道)  (pin 2，**必须固定，不能悬空**)
VDD (pin 5) ── 1.65~3.63 V + 0.1 µF 去耦
GND (pin 3) ── 地
SD 线       ── 建议加 100 kΩ 下拉到 GND（datasheet 要求，SD 三态时给线放电）
```

- 16kHz / 32bit / 立体声帧，每帧 64 SCK，SCK = 1.024MHz；ICS-43434 输出 24bit 二进制补码、MSB first、Philips I²S（MSB 比半帧起点晚 1 个 SCK），与固件 `I2S_STD_PHILIP_SLOT_DEFAULT_CONFIG` 匹配。
- LR 接低 = 左声道（WS 下降沿后输出），接高 = 右声道（WS 上升沿后输出）。固件两个声道一起统计，接高接低都能用，**但悬空会导致输出不确定**。
- **datasheet 明确：VDD 没供电时不要给 SCK/WS 时钟**，会持续导通 ESD 保护二极管影响可靠性；量到 VDD 没电就先断电。
- 封装是 6 脚 LGA（top view / terminal side down），进音孔在顶面，**容易焊反 180°**，焊反会把 6 个脚全接错。
- `GET /api/mic` 返回 `{"ok":true,"rms":N,"peak":N,"rate":16000}`；诊断版额外返回 `nz`（128 个 32bit 样本里非 0 的个数）和 `raw`（前 8 个原始样本 hex）：
  - `nz=0` 且 raw 全 0 → SD 线上根本没有信号（供电 / LR / 焊接 / 时钟），**与固件无关**
  - `nz>0` 但 rms=0 → 有效数据落在低 8 位被 `>>8` 抹掉（固件问题）
- 本固件**只做电平自检**，不录音、不做语音唤醒。

## 5. WS2812B ×2

```
GPIO10 ──[ 330Ω 可选 ]── DIN(第 1 颗) → DOUT → DIN(第 2 颗)
5V / GND 各自就近 100nF 去耦
```

- 两颗串联，共用一根数据线；GPIO10 用 RMT 一次推满 2×24bit（内核的 `rgbLedWrite()` 一次只推一颗，分两次会被识别成两帧，第二颗拿不到数据）。
- 3.3V 数据驱动 5V 供电的 WS2812B 同样处在 VIH 边缘；点亮异常时先降 VDD 或加一级电平转换。
- 默认行为：平时暖白微光（网页 1~10 档），夜间时段跟着压暗；等待配网蓝闪、闹铃红闪；网页「氛围灯」可一键全关。

## 6. 与 Sense 扩展板的冲突（装机前必看）

如果用的是 **XIAO ESP32-S3 Sense 模组 + 摄像/SD 扩展板**，扩展板默认还占着几根脚：

| 扩展板功能 | 占用 | 与本板的冲突 |
|---|---|---|
| microSD 卡（J3 默认连通） | GPIO7=SCK、GPIO8=MISO、GPIO9=MOSI、GPIO21=CS，且 SD 座上有上拉 | **直接压在 GPIO7/8/9 的 I2S 音频上** |
| 摄像头 | GPIO10=XMCLK + GPIO11~18/38~40/47/48 | **压在 GPIO10 的 WS2812B 上** |
| 内置 PDM 麦克风 | GPIO41/42 | 本固件不用，无冲突 |

**结论：本板只装 XIAO 模组，不要叠 Sense 扩展板。** 若已叠了扩展板，必须断开 SD 的 J3 焊盘并拔掉摄像头，否则音频和彩灯都不正常；GPIO21 也不要再复用。

## 7. 电源与启动

| 项 | 要求 |
|---|---|
| 5V | 灯板、WS2812B、MAX98357、ICS-43434 的 VDD 按各自 datasheet；功放瞬时电流留足 |
| 3V3 | 由 XIAO 模组板载 LDO 提供（可从模组 3V3 脚取，别再叠一路 LDO 对打） |
| USB | 模组原生 USB-C；串口日志走 USB CDC（硬件 CDC/JTAG），115200bps |
| Flash | 8MB，分区 `default_8MB`：app0 @ `0x10000`（3MB），NVS @ `0x9000` |
| PSRAM | 固件按「关闭」编译，避免模组批次差异导致启动失败 |

### 上电自检对照（串口 115200）

```
[RGB] WS2812B×2 ok  GPIO10
[SPK] MAX98357 I2S ok  BCLK=8 LRCK=9 DIN=7  44100Hz/16bit
[MIC] ICS-43434 I2S ok  SCK=5 WS=4 SD=6  16000Hz/32bit
[BOOT] XiaoMiClock v4.0  WiFi=(未配置)          ← 或已配置的 SSID
[AP] 热点 XiaoMiClock 已开  http://192.168.4.1
[NTP] 校时成功 2026-11-15 11:03:20
```

| 现象 | 排查方向 |
|---|---|
| 屏上一直闪等待动画 | 没有 RTC，必须联网校时；先确认 WiFi 连上、`/sync` 返回 ok |
| 屏全暗 / 乱码 | GPIO1 接反或 TM1652 电平不够；先量 SDA 空闲是否为 3.3V 高 |
| 完全无声 | GPIO7/8/9 接反、MAX98357 的 SD 脚被拉低、或叠了 Sense 扩展板占用了这三脚 |
| `/api/mic` 全 0 不动 | 16:50 诊断版实测 `nz=0`、`raw` 全 `00000000`，排除固件与 I2S 配置，确认 **SD 线无信号**；**17:00 重新加焊麦克风后已修复**（`nz=64`、RMS 1441~5820 波动），根因是虚焊。复发时按序查：VDD(1.65–3.63V) → LR 是否固定 GND/VDD → SCK 是否有 1.024MHz → SD 到 GPIO6 连通性 → LGA 封装是否焊反 180°；详见第 4 节 |
| 彩灯不亮 / 只有第一颗亮 | GPIO10 接了摄像头扩展板，或电平不够；确认 RMT 单帧推了 48bit |
| 开机直接进下载模式 | 上电时按住了 GPIO0 的 BOOT 键 |
| 按键主键开机就被当成按下 | `keyTask()` 有 `keyArmed` 防误触，先松开一次；若仍异常查 GPIO0 上拉 |

## 9. 电源域与 32.768 kHz 晶振（硬件红线，16:08 实测确认）

> 第一版板子把 `VDD3P3_RTC` 漏接了，芯片完全不启动、USB 不枚举，排查了很久才定位。列为红线，改板必须保留。

| 项 | 结论 |
|---|---|
| `VDD3P3_RTC` | **必须接 3.3 V**（范围 3.0–3.6 V），就近加 0.1 µF 去耦；**绝不能悬空** |
| 为什么致命 | 官方《ESP32-S3 原理图设计指南》：它是「RTC 及部分数字电源」；`VDD_SPI` 由它经片内约 14 Ω 供电，再给 3.3 V Flash / PSRAM 供电；且「VDD3P3_RTC 不能单独供电工作，所有电源必须全部上电」 |
| 挂在它上面的信号 | `CHIP_PU`、GPIO0~14、GPIO19/20（USB D+/D−）、`XTAL_32K_P/N`、`VDD_SPI`。没电 = 复位采样 + USB PHY + Flash 全废 |
| 典型症状 | 插 USB 完全静默、系统里没有 VID 0x303A、按 BOOT+RESET 无效、CH340 口 0 字节回包 |

**32.768 kHz 晶振（X2）**

- 引脚没接错：GPIO15 = `XTAL_32K_P`、GPIO16 = `XTAL_32K_N`（官方 DevKit 引脚表）。这两个脚同属 `VDD3P3_RTC` 域，RTC 域没电时 32K 振荡器根本不工作，晶振只是挂在无电引脚上的无源负载；拆掉它减少了一条经 ESD 二极管的异常漏电路径，但**补 3.3 V 才是根因**。
- **能装，但当前固件不需要**。ESP-IDF 的 RTC 时钟源默认就是**内置 136 kHz RC 振荡器**（不依赖任何外部元件、Deep-sleep 功耗最低，温漂稍大）；可选项还有外部 32 kHz 晶振（更稳、Deep-sleep +1 µA）、内置 17.5 MHz/256 ≈ 68 kHz（更稳、+5 µA）、外部有源 32 kHz。要用外部晶振必须软件显式设置 `CONFIG_RTC_CLK_SRC_EXT_CRYS`，否则振荡器不启用，晶振白接。
- 本固件时间走 NTP/SNTP、无 DS1302、不用深度睡眠，RTC 时钟源不影响走时精度 → **建议保持不装 X2**，GPIO15/16 还能留作 U0RTS/U0CTS 或 ADC2_CH4/5。
- 若坚持装：除供电外，还需按晶振 CL 在 XTAL_32K_P/N 各加 6–12.5 pF 对地负载电容（官方 XIAO 参考设计里没有这颗晶振，只有 X1 40 MHz 主晶振 + C7/C8 10 pF），且 GPIO15/16 不得再挪作他用。

**顺带实测到的芯片信息**：ESP32-S3 QFN56 rev0.2、8 MB 内嵌 PSRAM（AP_3v3）、40 MHz 主晶振、**Flash 16 MB**。当前固件按 8 MB 分区编译可正常运行，只是没用满后 8 MB。
